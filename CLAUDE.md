# AskMyCity

SharkByte 2026 hackathon project. Devpost closes Sunday Nov 8, 11:00 a.m. EST. Feature freeze 9:00 a.m.
Prizes: Best Overall, Best Use of Swarms API, Best Use of Prune API.

## What it is

One box. A resident of the City of Miami or Miami Gardens types or speaks a need in Spanish, English or Haitian Creole and gets ONE card: what it means, one step, official link, official phone.

## Architecture

- `data/resources.json` is the single source of truth (24 entries: 13 City of Miami, 11 Miami Gardens; es/en/ht).
- `backend/askCity.function.js` is the function LIVE in Base44 (keyword router; Swarms + Prune in admin demo mode). If you change a fact in `data/resources.json`, change it there too.
- `src/askcity.mjs` is the core: rules router → (if tie or no match) Prune intake → Swarms Finder → Judge → code guardrail → card. On a tie Swarms may only choose among the tied entries; without AI keys, ties use the longest-matched-term tie-break.
- `base44/functions/askCity/entry.js` is GENERATED by `npm run build`. Never edit it by hand.
- The live UI is a Base44 app (https://ask-miami-now.base44.app). It calls the `askCity` backend function and shows `card`.

## Hard rules

1. The AI only picks a catalog id. Card text, links and phones always come from `data/resources.json`.
2. The guardrail rejects any id that is not in the catalog or belongs to the other city.
3. Never say "you qualify" / "calificas" / "kalifye". Programs say "may be for you".
4. Emergency words → "call 911" card, before anything else.
5. Never store user messages. Never log or return API keys. Never commit `.env`.
6. Only miami.gov and miamigardens-fl.gov URLs (the emergency card links to Miami-Dade County).

## Commands

- `npm test` must stay green (28 tests).
- `npm run eval:live` evaluates the deployed function on the same 42 questions.
- `npm run eval` (rules only) and `npm run eval:ai` (needs SWARMS_API_KEY) print accuracy, confident-wrong and invented links.
- `npm run build` after any change to the catalog or `src/`.
